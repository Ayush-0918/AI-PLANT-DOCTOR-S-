# Trained Model Weights & Artifacts

## Purpose
Destination directory for trained PyTorch model weight files generated after running training scripts on newly downloaded datasets.

## Expected Files
1. **`plantvillage_model.pth`**
   - **Architecture**: `MobileNetV3-Large` (or `EfficientNet-Lite`)
   - **Classes**: 38+ plant disease classes + background
   - **Generated by**: `python backend/scripts/train_lite.py`
   - **Consumed by**: `backend/app/ai_model.py`, `backend/scripts/evaluate_field.py`
2. **`soil_classifier.pth`**
   - **Architecture**: `MobileNetV2` / `ResNet18`
   - **Classes**: 5–6 soil types
   - **Generated by**: `python backend/scripts/train_soil_model.py`
   - **Consumed by**: `backend/app/services/diagnosis/ai_inference_service.py`
3. **`soil_labels.txt`**
   - Soil class names corresponding to `soil_classifier.pth` outputs.
